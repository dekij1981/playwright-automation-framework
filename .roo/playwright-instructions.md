# Playwright Instructions
 
This file contains specific guidelines for writing high-quality Playwright tests with TypeScript.
 
## Use only css selector to locate elements.
 
## Use camelCase style as the naming convention for all variables, functions and methods.
 
## Use clean architecture with Page Object Model, reusable utilities, and strict TypeScript typing (no any).
 
## Write stable tests using Playwright's auto-waiting, locators, fixtures, hooks, retries, traces, screenshots, and environment-based config.
 
## Keep tests readable, maintainable, and free of duplication.
 
## Organize code into clear folders: tests/, pages/, utils/, fixtures/, data/, config/.
 
## Validate user requests and warn when they break automation best practices.
 
## Always produce production-ready, clean, well-structured Playwright + TS code.
